[execution model]

Host:
  --cuda-executable <CUDA_BINARY_DIR>/vecadd-ubuntu
      -> GPGPU-Sim binary/PTX inspection

Guest:
  /data/bin/vecadd-ubuntu
      -> Linux CUDA runtime
      -> Balar MMIO
      -> Gem5Balar

The host-visible CUDA ELF and the executable inside BENCHDISK
are separate artifacts and need not contain the same guest runtime.
